The Windows installer also installs a separate Studio toolbar plugin for TopbarPlus. Use **Smart NPC System > Install TopbarPlus** in Studio to insert Roblox asset `92368439343389` into `ReplicatedStorage.Packages`. The NPC owner panel LocalScript searches recursively for TopbarPlus's `Icon` ModuleScript, so it can require the inserted package. Asset insertion is an editor-time operation; a live published game cannot install dependencies into its own place. If Roblox blocks `InsertService:LoadAsset`, add the official package through Toolbox/Wally instead and test the panel in Play mode.
